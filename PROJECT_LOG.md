# Project 001 — Dasmoto's Arts & Crafts

**Status:** Completed
**Project Type:** Guided Front-End Development Project
**Course:** Codecademy — Web Foundations
**Primary Focus:** HTML5 and CSS3

## Project Overview

Dasmoto's Arts & Crafts is a static webpage for a fictional arts and crafts retailer.

The project was completed as part of Codecademy's Web Foundations training and required recreating a webpage from a provided design specification.

The finished page includes a large photographic header and separate product sections for brushes, frames, and paints.

## Technologies

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code

## What I Built

I created the webpage structure using HTML and styled the page using an external CSS stylesheet.

The page includes:

- Main page header with a background image
- Brushes section
- Frames section
- Paint section
- Product images
- Product descriptions
- Pricing information
- Custom typography and section styling

## Development Process

I started by reviewing the provided design specification and identifying the major sections required for the webpage.

I then created the HTML structure and added the required text and image content.

After the structure was complete, I used CSS to reproduce the visual design, including typography, section headings, colors, product styling, and the main photographic header.

Git was used to track the project, and the completed source code was pushed to GitHub.

## Primary Challenge

The most difficult part of the project was getting the background image for the main header to display correctly.

This required me to investigate how CSS background properties work and understand how multiple properties affect the final appearance of a background image.

## How I Solved It

I reviewed the CSS controlling the header and experimented with the relevant background properties until I understood which settings were preventing the image from displaying as expected.

Rather than only finding a combination that worked, I focused on understanding why the properties affected the image.

This helped me better understand CSS background images and gave me more experience troubleshooting styling problems.
