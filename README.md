## 📌 Featured Project

### 🎨 Dasmoto's Arts & Crafts

My first documented front-end development project.

Dasmoto's Arts & Crafts is a static webpage for a fictional arts and crafts retailer that I created as part of Codecademy's Web Foundations training.

I built the page from a provided design specification using **HTML5 and CSS3**, including product sections, images, typography, and a photographic background header.

One of the biggest challenges was getting the CSS background image to display correctly. Troubleshooting the issue helped strengthen my understanding of how CSS background properties interact and reinforced a systematic approach to debugging front-end problems.
